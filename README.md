Mini Blockchain System 🔗
Built a foundational blockchain model from scratch to understand how decentralized systems actually work behind the scenes.
✨ Key Features:
🔹 Block creation with transaction data
🔹 SHA-256 cryptographic hashing
🔹 Genesis block implementation
🔹 Hash linking between blocks
🔹 Blockchain validation system
🔹 Tamper detection mechanism

🛠️ Tech Stack:
💻 JavaScript
⚙️ Node.js
🔐 Crypto-JS
This project helped me explore core blockchain concepts like:
✔️ Cryptographic Hashing
✔️ Immutable Data Structures
✔️ Block Validation
✔️ Distributed Ledger Fundamentals
One of the most interesting parts was seeing how changing even a small piece of data breaks the entire chain integrity — showcasing the real power of blockchain security.
